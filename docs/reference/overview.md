# 组件与 SDK

> **开发中**：以下为文档分类占位，暂不提供具体 API 或业务使用示例。

## 组件

面向智能体应用的任务交互与结果展示。组件可用后，将提供使用示例、属性说明和交互用法。

## SDK

面向智能体应用的能力接入。SDK 可用后，将提供初始化、调用方式、参数与返回值说明。

## 如何开始

首次使用请前往[快速开始](/guide/getting-started)；服务对接相关内容请前往[协议接入](/protocol/integration)。这些指南会随对应能力开放逐步补充。
